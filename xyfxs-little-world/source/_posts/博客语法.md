## 1. Hexo 文章的基本结构

你写的文章文件一般是这样开头的：

```md
---
title: 我的第一篇博客
date: 2026-05-28 12:00:00
tags:
- Hexo
- 教程
---
```

这部分叫“Front-matter”，Hexo 用它来识别文章标题、时间、标签等信息。

Front-matter 后面，就是正文内容，用 Markdown 写。

---

## 2. 常用 Markdown 语法

### 标题
```md
# 一级标题
## 二级标题
### 三级标题
```

### 段落
直接写一句话，空一行就是新段落：
```md
这是第一段。

这是第二段。
```

### 加粗 / 斜体
```md
**加粗**
*斜体*
```

### 链接
```md
[Hexo 官网](https://hexo.io/)
```

### 图片
```md
![描述文字](/images/avatar.gif)
```

### 列表
无序列表：
```md
- 第一项
- 第二项
```

有序列表：
```md
1. 第一项
2. 第二项
```

### 代码
单行代码：
```md
`hexo new post "标题"`
```

多行代码块：
```md
```bash
hexo server
```
```

### 引用
```md
> 这是一个引用
```

### 分割线
```md
---
```

## 3. 结合 hello-world.md 的例子

你的 hello-world.md 其实就是标准写法：

- 开头只有 `title`
- 然后正文直接写文字
- 里面用了链接 `[Hexo](https://hexo.io/)`
- 还用了标题 `## Quick Start`、`### Create a new post`
- 用代码块展示了 `hexo new`、`hexo server`

你可以照着它写：

```md
---
title: 帝雾刃革征豪万
date: 2026-05-28 13:00:00
tags:
- 小说
- 日记
---

# 帝雾刃革征豪万

这是我的第一段内容。

## 小节标题

- 这里是第一点
- 这里是第二点

```bash
echo "写博客很简单"
```
```

---

## 4. 你现在最常用的写法

你写博客时，最常用的是：

- `#`、`##` 做标题
- `**...**` 做重点
- `[](...)` 做链接
- `-` 或 `1.` 做列表
- `` `...` `` 和 ``` ``` 做代码

---

## 5. 预览方式

写完后，回到项目根目录运行：

```bash
npm run server
```

然后在浏览器打开本地地址，就能看到你的文章。
